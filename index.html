What is meeEL

meeEL is a simple language. You write plain English. meeEL turns it into real code that runs on any device.

You write one meeEL file. meeEL makes four files:

From meeELWhat you get
home.htmlThe page structure
home.cssColors and sizes
home.jsThe click actions
server.pyA small server

Only three symbols

meeEL has only three symbols:

  • - joins words in a name
  • [ ] holds a value
  • # marks a note (meeEL will not read it)

Example:

page-[
  background-[white]  # make the page white
  title-[
    content-[Hello!]  # the greeting text
  ]
]

Nothing else. No semicolons. No brackets outside of values.

Why we built it

HTML, CSS, JavaScript and Python are powerful — but they have a steep learning curve. A 12-year-old with an idea cannot build a site without months of study.

meeEL gives them the same power with the simplest possible syntax. The name of every block says what it does. There are no cryptic shortcuts. No jargon.

The seven libraries

Everything you need is a tap away — inside the Tools drawer:

  • Blocks — 152 building blocks (pages, cards, forms, tables)
  • Actions — 112 things your app can do (show, hide, fetch, beep)
  • Properties — 153 settings (colors, sizes, shadows)
  • Tokens — 150 style words (bold, round, hidden)
  • Fonts — 106 typefaces ready to use
  • Colors — 100 named colors plus a picker
  • Icons — 132 built-in icons

What meeEL can do

Landing pages, portfolios, dashboards, restaurant menus, forms, quiz apps, to-do lists, calculators, dark-mode sites, multi-page sites, and installable apps.

What meeEL cannot do

meeEL is a frontend language. It does not store data, handle accounts, or process payments. There is no database, no login system, no backend by design.

But meeEL can talk to any backend — Supabase, Firebase, MongoDB, or your own server — using the bring and bring-json actions.

Privacy

No account. No login. Your code stays in your browser. meeEL never sends anything to a server.

আপনি একটা meeEL ফাইল লিখবেন। meeEL চারটে ফাইল বানাবে:

meeEL থেকেআপনি যা পাবেন

মাত্র তিনটে চিহ্ন

meeEL-এ মাত্র তিনটে চিহ্ন:

  • - নামের শব্দগুলো জোড়া লাগায়

এর বাইরে কিছু নেই। কোনো semicolon নেই। মান ছাড়া বন্ধনী নেই।

meeEL তাদের সেই একই শক্তি দেয় — সবচেয়ে সহজ গঠনে। প্রতিটা block-এর নামেই বলা আছে সে কী করে। কোনো রহস্যময় সংক্ষেপ নেই। কোনো কঠিন শব্দ নেই।

How to Publish

How to Publish

When your meeEL code is ready, tap the blue Download button at the top right. Choose Download as ZIP — meeEL gives you all files packed together.

One meeEL file → four files
Your .meeel code becomes real HTML, CSS, JavaScript and a Python server.

Step 1 — Download your ZIP

  1. Tap the blue Download button at the top right.
  2. Choose Download as ZIP.
  3. You will get a file called meeEL-Codes.zip.

The ZIP contains:

  • home.html — your page structure
  • home.css — colors and sizes
  • home.js — click actions
  • home.meeel — your original code
  • server.py — a small Python server
  • README.md — full guide

Step 2 — See it on your own computer

Unzip the file. Inside the folder, just double-click home.html — it opens in your browser. That is your site, running on your device.

If you want the small Python server:

  1. Open a terminal in the folder.
  2. Run: python server.py
  3. Your browser opens at http://localhost:8000

Step 3 — Put it on the internet

You can host your site for free. Three easy options:

Option A — Render (recommended)

  1. Create a free account at render.com
  2. Create a new Static Site.
  3. Connect your GitHub repo — or drag your ZIP.
  4. Render gives you a live URL. Done.

Option B — Netlify

  1. Go to netlify.com/drop
  2. Drag your unzipped folder onto the page.
  3. Your site is live in 10 seconds.

Option C — GitHub Pages

  1. Create a GitHub repo.
  2. Upload the unzipped files.
  3. Settings → Pages → Source: main branch.
  4. Your site appears at yourname.github.io/repo

Step 4 — Install as a phone app

meeEL sites work like phone apps. Open your live site on your phone:

  • Android (Chrome): tap the ⋮ menu → "Install app"
  • iPhone (Safari): tap Share → "Add to Home Screen"

Your site now sits on the home screen like a real app. It works offline too.

About your API keys

If you used connections-[...] to store a Supabase or Firebase key, meeEL separates those from your code and puts them in a .env file. Your real key never goes into the HTML or JavaScript.

Never put a service-role key or private key into a public site. Only publishable keys belong in the browser.

Need help?

Open the Learn to write book inside the Tools drawer — it walks through everything chapter by chapter.

প্রকাশ করবেন কীভাবে

আপনারmeeEL কোড রেডি হলে, উপরে ডানদিকে নীল Download বাটনে চাপুন। Download as ZIP বেছে নিন —meeEL সব ফাইল একসাথে প্যাক করে দেবে।

একটাmeeEL ফাইল → চারটে ফাইল
আপনার .meeel কোড সত্যিকারের HTML, CSS, JavaScript আর একটা Python সার্ভারে বদলে যায়।

ধাপ ১ — আপনার ZIP ডাউনলোড করুন

  1. উপরে ডানদিকে নীল Download বাটনে চাপুন।
  2. Download as ZIP বেছে নিন।
  3. meeEL-Codes.zip নামে একটা ফাইল পাবেন।

ZIP-এ থাকবে:

  • home.html — পেজের গঠন
  • home.css — রঙ আর আকার
  • home.js — ক্লিকের কাজ
  • home.meeel — আপনার আসল কোড
  • server.py — একটা ছোট Python সার্ভার
  • README.md — সম্পূর্ণ গাইড

ধাপ ২ — নিজের কম্পিউটারে দেখুন

ZIP খুলুন। ফোল্ডারের ভেতরে home.html-এ ডাবল-ক্লিক করুন — ব্রাউজারে খুলে যাবে। এটাই আপনার সাইট, আপনার ডিভাইসে চলছে।

Python সার্ভার চালাতে চাইলে:

  1. ফোল্ডারে একটা টার্মিনাল খুলুন।
  2. চালান: python server.py
  3. ব্রাউজার নিজেই http://localhost:8000-এ খুলবে।

ধাপ ৩ — ইন্টারনেটে তুলুন

ফ্রিতে হোস্ট করতে পারবেন। তিনটে সহজ উপায়:

উপায় ক — Render (সবচেয়ে ভালো)

  1. render.com-এ ফ্রি অ্যাকাউন্ট খুলুন।
  2. নতুন Static Site বানান।
  3. GitHub repo কানেক্ট করুন — বা ZIP ড্র্যাগ করুন।
  4. Render আপনাকে একটা লাইভ URL দেবে। ব্যস।

উপায় খ — Netlify

  1. netlify.com/drop-এ যান।
  2. ZIP-খোলা ফোল্ডারটা সোজা পেজে ড্র্যাগ করুন।
  3. ১০ সেকেন্ডে সাইট লাইভ।

উপায় গ — GitHub Pages

  1. একটা GitHub repo বানান।
  2. ZIP-খোলা ফাইলগুলো আপলোড করুন।
  3. Settings → Pages → Source: main branch।
  4. সাইট দেখা যাবে yourname.github.io/repo-এ।

ধাপ ৪ — ফোনে অ্যাপ হিসেবে ইনস্টল

meeEL সাইট ফোনের অ্যাপের মতো কাজ করে। ফোনে আপনার লাইভ সাইট খুলুন:

  • Android (Chrome): ⋮ মেনু → "Install app"
  • iPhone (Safari): Share → "Add to Home Screen"

এখন সাইটটা হোম স্ক্রিনে বসে থাকবে, অ্যাপের মতো। অফলাইনেও চলবে।

আপনার API key নিয়ে

connections-[...] দিয়ে Supabase বা Firebase key রেখে থাকলে,meeEL সেগুলো আলাদা করে .env ফাইলে রাখে। আসল key কখনো HTML বা JavaScript-এ যায় না।

কখনো service-role key বা private key পাবলিক সাইটে দেবেন না। শুধু publishable key ব্রাউজারে চলে।
